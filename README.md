# pm-tools
PocketMine Toolbox - a modern all-in-one utility app for PocketMine developers and server admins.




📦 Create & Extract .phar – build or unpack plugins instantly

🧩 API Injector – patch your plugin.yml effortlessly

💥 Crashdump Parser – understand error dumps like a pro

📂 Skeleton Generator – kickstart new plugins in seconds

🌐 Poggit Search – find plugins without leaving the app

🎨 MOTD Generator – craft stylish server messages with color codes

📡 Ping Server – test live status in one click

⚙️ Server Manager + Console – start, stop, and control your server live
